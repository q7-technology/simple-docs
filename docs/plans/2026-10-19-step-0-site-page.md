# Simple Docs step 0: the project page on the Q7 site

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Publish `/projects/simple-docs` on the Q7 Technology website as an
in-development project, with every place that lists projects updated to
include it, built and checked locally on a branch, and **not** merged or pushed
without the user's say-so.

**Architecture:** The site (`q7-technology`, Vite + React + TypeScript +
Tailwind) has a project registry in `src/data/projects.ts` that the homepage
Projects section and `/projects` both read. Each project has a lazily loaded
page under `src/pages/`, a route in `src/App.tsx`, an SEO entry in
`STATIC_ROUTE_META` (`src/lib/routeMeta.ts`) that both `<Seo>` and the
build-time prerenderer (`scripts/prerender.mjs` via `src/prerender/entry.tsx`)
read, and a hand-listed line in `scripts/generate-sitemap.mjs` (run as
`prebuild`, writing the committed `public/sitemap.xml`). The new page copies
the shape of `src/pages/SimpleLmsPage.tsx` and its shared building blocks in
`src/components/projects/ProjectBits.tsx`. No new components, no new
dependencies, no images.

**Tech Stack:** React 18, react-router-dom 7, Tailwind 3, lucide-react 0.462,
react-helmet-async, Vite 7. Lint is ESLint 9 (`npm run lint`). There is **no
test runner** in this repo (no vitest/jest); verification is `tsc`, ESLint,
`npm run build` (which also runs the sitemap and prerender scripts) and a
visual check in `npm run preview`.

**Repos and paths**

- Plan lives in: `~/Q7 Technology/Software/q7/simple-docs/docs/plans/`
- Every edit is in: `~/Q7 Technology/Software/q7/q7-technology` (call it `SITE`
  below: `SITE="$HOME/Q7 Technology/Software/q7/q7-technology"`)

**Hard rules for whoever runs this plan**

1. The site deploys to production on Cloudflare Pages on **every push to
   `main`**. All work happens on branch `simple-docs-page`. Never commit to
   `main`, never push `main`, never merge. Do not push the branch either until
   the user says so (Task 7).
2. The page links to `https://github.com/q7-technology/simple-docs`. The user
   has created that repository; before merging, Task 7 confirms it is public
   and has the design pushed (a private or empty repo is a merge blocker).
3. Other agents commit to `q7-technology` too. Stage files **by explicit path**
   only (`git add <path>`), never `git add -A` or `git add .`.
4. Copy follows the Q7 voice (`design-system/README.md`): plain Australian
   English, a number or a mechanism behind every claim, sentence case, no hype
   words, no emoji. The page uses no screenshot or mock UI because nothing runs
   yet; if one is ever added before release it must carry the gold
   **Simulated demo** label.
